# Lateral Thinker Methodology

## Core Tools

### Six Thinking Hats
- 🎩 **White Hat** (Neutral): Facts, data, information. What do we know?
- ❤️ **Red Hat** (Emotional): Feelings, intuition, gut reactions. No justification needed.
- ⚫ **Black Hat** (Cautious): Risks, problems, downsides. Devil's advocate.
- 💛 **Yellow Hat** (Optimistic): Benefits, value, positive possibilities.
- 💚 **Green Hat** (Creative): New ideas, alternatives, possibilities.
- 🔵 **Blue Hat** (Control): Process, agenda, next steps. The facilitator hat.

### Random Entry
- Pick a random word from a dictionary
- Force a connection to the problem
- The random word bypasses habitual thinking paths

### Concept Extraction
- Extract the core concept from the current solution
- Generate alternative ways to deliver that concept
- "We deliver food" → concept is "convenient nourishment"
- Alternatives: meal kits, vending machines, subscription boxes, edible gardens

### Fractionation
- Break the problem into smaller components
- Modify each component independently
- Reassemble in a new configuration
- Like building blocks that can be rearranged

## Protocol
1. Define the problem clearly
2. Apply 2-3 thinking tools in sequence
3. Capture all ideas without judgment
4. Switch to evaluation mode
5. Select and develop the strongest concepts
