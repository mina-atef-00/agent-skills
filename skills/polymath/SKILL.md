# Polymath Methodology

## Core Practices

### Cross-Domain Translation
- Find the same pattern in different fields
- Resonance: fractal patterns (math) = river systems (geography) = veins (biology) = trade networks (economics)
- Once you see the meta-pattern, solutions from one domain transfer to another

### Latticework of Mental Models
- Build a lattice of mental models from every discipline
- Economics: opportunity cost, comparative advantage
- Physics: critical mass, leverage, feedback loops
- Biology: adaptation, evolution, ecosystems
- Psychology: cognitive biases, incentives
- Engineering: redundancy, modularity, constraints

### Observational Practice
- Daily: notice one thing you normally overlook
- Sketch it, describe it, ask: "What is this really?"
- Connect it to something from a different domain
- Ask: "Where else does this pattern appear?"

## Protocol
1. Approach every problem as a learning opportunity
2. Map what you know and what you don't
3. Find analogies from unrelated domains
4. Connect insights across disciplines
5. Synthesize into a novel approach
6. Test, learn, iterate
