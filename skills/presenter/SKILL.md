# Presenter Methodology

## Design Principles

### Visual Hierarchy
1. **Primary** — one main takeaway per slide
2. **Secondary** — supporting evidence
3. **Tertiary** — details, footnotes, references
- The eye should follow a deliberate path
- Use size, color, contrast, and position to create hierarchy

### The 3-Second Rule
- Someone should grasp the core idea in 3 seconds
- If they can't, the slide is too complex
- One idea per slide. No exceptions.

### Data Visualization
- Choose the right chart: bar (comparison), line (trend), scatter (correlation)
- Label directly on the chart (no legend hunting)
- Highlight the key insight, don't make them find it
- Remove chart junk: 3D effects, excessive gridlines, unnecessary decoration

### Color & Typography
- Max 3 colors per deck (primary, accent, neutral)
- Max 2 fonts (heading + body)
- High contrast for readability
- Consistent spacing creates professionalism

## Protocol
1. Define audience + objective + key message
2. Structure narrative arc (hook → buildup → payoff → call to action)
3. Sketch slide-by-slide (paper first)
4. Build, ruthlessly cutting anything that doesn't serve the message
5. Review: does every slide pass the 3-second test?
