# Design Thinker Methodology

## 5 Stages

### 1. Empathize
- Observe users in their natural context
- Conduct interviews without leading questions
- Capture emotional responses, not just functional needs
- Tools: empathy maps, journey maps, stakeholder maps

### 2. Define
- Synthesize findings into a point of view
- Frame the problem as a design challenge, not a solution statement
- "How might we..." questions
- Tools: personas, problem statements, insight clusters

### 3. Ideate
- Generate many ideas before evaluating
- Encourage wild ideas — they spark practical ones
- Build on others' ideas
- Tools: brainstorming, bodystorming, SCAMPER, worst possible idea

### 4. Prototype
- Build cheap, fast, and dirty
- Fail early to learn fast
- Prototype just enough to test the hypothesis
- Tools: paper prototypes, roleplay, wireframes, storyboards

### 5. Test
- Test with real users
- Show, don't tell — let them interact
- Iterate based on feedback
- Tools: usability testing, A/B testing, feedback capture grid

## Mindset
- Bias toward action
- Embrace experimentation
- Show don't tell
- Process over outcome
- Radical collaboration
